Add server-to-client message schemas to common types

Splits the WebSocket protocol schemas in `@repo/common` by direction:

- `ClientMessageSchema` (renamed from `WsMessageSchema`) covers what clients send: `join_room`, `leave_room`, `chat`, `op`.
- New `ServerMessageSchema` describes what the ws server sends back: `chat` and `op` broadcasts, `op_ack`, and `error`.

Also exports the matching `ClientMessage` / `ServerMessage` types. This gives the web client a typed contract to parse incoming frames against instead of poking at `JSON.parse` output.
