backend-common: read JWT secret from AUTH_JWT_SECRET

Groups auth configuration under an `AUTH_` prefix so those variables sort together in the Railway panel and can't collide with platform-provided ones.

- `JWT_SECRET` is now read from `AUTH_JWT_SECRET`
- the inline check is replaced by a small `required()` helper so further settings can be added the same way

The exported `JWT_SECRET` constant is unchanged, so neither backend needs code changes.
