useSocket: make reconnect behaviour configurable

Adds an options object to `useSocket`:

```ts
useSocket({ reconnect?: boolean; maxDelayMs?: number })
```

- `reconnect`: retry with exponential backoff when the connection drops
- `maxDelayMs`: cap for the backoff delay (default 5000, the previous hard-coded value)

Short-lived views like the chat room don't need to keep retrying in the background, so reconnecting is now something a caller opts into.
