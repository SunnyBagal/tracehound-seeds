Report embedding API failures instead of returning null

`generateEmbedding` returned `null` both when embeddings were disabled and when the OpenAI call failed, so the two cases looked identical.

It now returns `null` only when `OPENAI_API_KEY` is unset. Network and API errors throw an `EmbeddingError` that carries the HTTP status, so an outage or exhausted quota is reported rather than looking like "embeddings turned off".
